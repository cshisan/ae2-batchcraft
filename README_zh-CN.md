# AE2 BatchCraft

**让一套处理样板服务整条并行产线。**

Minecraft **1.21.1** · **NeoForge** · **Applied Energistics 2** · 项目版本 **2.0.1**

[English](README.md) | **简体中文**

## 简介

AE2 BatchCraft 通过样板 P2MP 网络，将一个 AE2 样板供应器连接到多台加工机器。
样板集中放在供应器中，扩建时增加输出端和机器即可。
对于需要分别连接输入、输出面，或需要世界交互、红石控制的加工流程，可以用单元管理器组合多个功能端口。

支持两种加工链路：

```text
样板供应器 → 输入端 → 输出端 → 机器
样板供应器 → 输入端 → 单元管理器 → 单元端口 → 机器／世界
```

输入端占用一个 AE 频道，输出端、单元管理器和单元端口不额外占用频道，但仍需接入有电的 AE 网络并保持区块加载。
这一频道规则适用于上述任务分发部件；ME IO 端口等其他设备有各自的运行要求。

## 主要功能

| 物品／功能 | 用途 |
|---|---|
| **样板 P2MP 输入端** | 接收处理任务，通过轮询、随机或优先级选择可用输出端或单元，支持完整下发和批次分发。 |
| **样板 P2MP 输出端** | 向相邻机器投料，并将产物返回原样板供应器；支持主动提取产物和持续供应资源。 |
| **样板 P2MP 单元管理器** | 将多个端口组合成一个加工单元。频率用于选择输入端，单元 ID 用于区分单元；提供福鲁伊克斯原色及 AE2 线缆颜色。 |
| **单元端口** | 传输、掉落、放置、返回、提取、收集、破坏、红石和供应九种端口，覆盖材料投送、产物回收、世界交互和库存补充。 |
| **PP2MP 样板** | 编写处理配方，设置材料输出方式、方向、批次数量，以及假合成使用的真实产物标记。 |
| **样板 P2MP 资源接收端** | 接收或主动获取资源，向同频率输出端和供应端口持续供料，无需合成任务；支持资源过滤和目标库存数量。 |
| **假合成转换器** | 用配对的物品票据表示任务，在标记的真实产物返回并达到数量要求后交付假产物票据。 |
| **ME 部件放置器** | 在点、线或平面范围批量放置线缆与部件，每轴最多 16 格；支持网络取料、内存卡配置和缺料合成请求。 |
| **ME IO 端口** | 填充或清空存储元件，并将处理完成的元件转移至本机输出槽、指定相邻容器，或按优先顺序选择可用目标。 |

## 快速上手

### 连接普通机器

1. 在合成网络的样板供应器中放入处理样板。
2. 为 P2MP 部件搭建一个通电的 AE 网络，可以使用独立子网。让输入端正面朝向供应器的输出面，并为输入端提供频道。
3. 在输入端所在的 AE 网络中，为每台机器安装一个正面朝向机器的输出端。
4. 手持 AE2 内存卡，潜行右键输入端保存频率，再右键各输出端加载。
5. 配置机器连接面，使其允许投料和产物返回。可以让机器主动把产物推入输出端，也可以在输出端设置中开启产物提取。
6. 在 AE2 中下单。输入端向可用执行端分配任务，产物通过原样板供应器返回。

频率 `0000` 表示未配置。相同频率不能跨越独立 AE 网络，也不能代替区块加载或机器自身的输入、输出面设置。

### 组合单元端口

1. 在输入端所在的 AE 网络中安装单元管理器和需要的端口。
2. 用内存卡为管理器加载输入端频率。
3. 潜行右键管理器保存配置，再右键各端口加载频率与单元 ID。
4. 使用传输、掉落或放置端口投料；按需增加返回、提取、收集或破坏端口回收产物，需要信号触发时增加红石端口。
5. 材料需要指定输出方式时使用 PP2MP 样板。多个管理器可共用输入端频率，但各单元应使用独立的单元 ID。

传输、掉落和放置端口负责投料，还需安排产物返回路径。
绑定和端口配置详见[单元管理器指南](neoforge1211/src/main/resources/assets/ae2_batchcraft/ae2guide/_zh_cn/unit/manager.md)。

## 加工配置

### 输出型端口投料模式

在管理器的“通用”分页中配置“输出型端口-投料模式”，也可在端口关闭同步后独立设置。
以下四种模式互斥，适用于**传输、掉落和放置端口**：

| 模式 | 每个端口在一笔任务中的行为 |
|---|---|
| **普通** | 可投送多个材料槽中的多种资源。 |
| **槽位独占** | 只负责分配到的一个材料槽。最后一个非空材料槽之前的空槽也占用端口，末尾空槽不占位。 |
| **单个物品** | 整笔任务最多投送一个物品或 1000 mB 的同一种流体，不是每 tick 投送一次。 |
| **同类型** | 只投送一种具体资源，可以来自多个材料槽。圆石与橡木、水与熔岩，以及数据组件不同的物品，分别视为不同资源。 |

修改模式从下一笔任务生效，现有端口必须足以分配整笔材料。
槽位独占下，`[A][空][B]` 均使用普通材料输出方式时，需要三个传输端口；中间端口只占位，不接收材料。

### PP2MP 样板与批次

右键 PP2MP 样板打开编码界面；右键已接入网络的 AE 方块，还可在编码时访问网络库存。
PP2MP 样板用于处理配方。

- 鼠标悬停材料槽，按 `Ctrl + 鼠标中键` 设置输出方式和方向；空材料槽也可配置，用于槽位占位。
- 鼠标悬停第一个产物，按 `Ctrl + 鼠标中键` 设置批次数量，再在输入端选择“批次分发”。
- 例如 `4A + 4B → 4C` 设置为两批，每批为 `2A + 2B → 2C`。
  材料、产物及存在时的真实产物标记数量都必须能被批数整除，每批仍需满足机器的实际配方。
- “完整下发”将整份配方交给一个输出端或单元；“批次分发”按配置拆分，不会为容量较小的机器自动缩小每批数量。

详见 [PP2MP 样板](neoforge1211/src/main/resources/assets/ae2_batchcraft/ae2guide/_zh_cn/pattern.md)
和[批次分发](neoforge1211/src/main/resources/assets/ae2_batchcraft/ae2guide/_zh_cn/batch.md)。

### 阻挡与产物返回

**阻挡模式默认开启：** 执行端等待当前任务完成后再接单。
关闭后，上一笔材料全部送出且能够接收新材料时，即可继续接单，无需等待上一笔产物。

产物返回匹配与阻挡模式是不同设置。产物提取间隔最小为 **1 tick**，实际吞吐仍受来源、机器接口和返回容量限制。
匹配规则、配置同步和任务重置说明见[公共配置](neoforge1211/src/main/resources/assets/ae2_batchcraft/ae2guide/_zh_cn/configuration.md)。

## 辅助自动化

- **持续供应：** 将资源接收端连接到来源，并与目标输出端或单元管理器绑定相同频率；单元使用供应端口接收资源。
  可通过过滤维持目标库存，无需发起合成。普通资源供应必须配置频率。
  支持的 Applied Flux FE 资源还可为所在 AE 网络充电，此用途无需频率，但不能直接连接普通 FE 能源线。
- **假合成：** 在同频率的假合成转换器中配对输入票据和假产物票据，再将 PP2MP 样板中的票据材料标记为假合成。
  “编写”按钮上方会显示独立的真实产物标记槽，该标记不会增加样板副产物。
  同一网络同一频率只能使用一台转换器，必须完成票据配对，并让真实产物返回达量。
- **批量放置：** ME 部件放置器可使用工具内材料或已绑定无线 AE 网络中的材料。
  鼠标拿起内存卡后，右键界面中的频率或单元 ID 色块加载该项，左键清除。
  创造模式免工具电量，但仍消耗材料；使用网络材料时仍需有效无线连接。
- **存储元件处理：** ME IO 端口可选择转移至本机槽位、外部容器，或优先使用其中一方、另一方作为备用。
  设备需要电力和频道。

## 运行环境与安装

当前源码面向 **Minecraft 1.21.1 NeoForge**，未包含 Forge 或其他 Minecraft 版本模块。

| 组件 | 本项目配置版本 | 要求 |

| NeoForge | `21.1.238` | 元数据允许 `21.1+` |

## 从源码构建

使用 **JDK 21**，在仓库根目录运行自带的 Gradle Wrapper。
`shared` 模块使用 Java 8 工具链，项目已配置由 Gradle 获取所需工具链；首次构建需要联网下载依赖。

```powershell
# Windows PowerShell：构建两个模块并运行测试
.\gradlew.bat buildAll

# 仅运行单元测试
.\gradlew.bat :shared:test :neoforge1211:test

# 启动开发客户端
.\gradlew.bat :neoforge1211:runClient
```

Linux 或 macOS 使用 `./gradlew` 替代 `.\gradlew.bat`。

模组产物为 `neoforge1211/build/libs/ae2-batchcraft-1.21.1-2.0.1-neoforge.jar`，
其中已包含公共模块代码，无需另行安装 `shared` 模块的 JAR。

| 目录 | 内容 |
|---|---|
| `shared/` | 不依赖平台 API 的 Java 8 公共代码 |
| `neoforge1211/` | Minecraft 1.21.1 NeoForge 实现、资源、指南和测试 |
