# AE2 BatchCraft

**让一套处理样板，轻松驱动一组并行机器。**

Minecraft 1.21.1 NeoForge | Minecraft 1.20.1 / 1.16.5 / 1.12.2 Forge | Applied Energistics 2

[English](README.md) | **简体中文**

## 它能做什么？

AE2 BatchCraft 为 Applied Energistics 2 加入了一个 **一对多的处理样板 P2P 网络**。

样板 P2P 输入端从 AE2 样板供应器（旧版本 AE2 中为 ME 接口）接收处理任务，再将任务分配给多个机器输出端或样板 P2P
单元。扩建产线时，只需增加端点和机器，无需复制同一套样板，也不需要为每台机器分别占用 AE 频道。

## 模组内容

| 物品 / 功能               | 用途                                                                                                        |
|---------------------------|-------------------------------------------------------------------------------------------------------------|
| **样板 P2P 通道（输入）** | 接收处理任务、在可用端点之间分配任务，并把产物返回样板供应器或 ME 接口；这是唯一占用 `1` 个 AE 频道的端点。 |
| **样板 P2P 通道（输出）** | 将材料送入一台相邻机器并接收返回产物；不占用 AE 频道。                                                      |
| **样板 P2P 通道（能量）** | 为 AE 子网供能，并把剩余 FE 分配给符合条件的机器和单元能量端口；无需 AE 频道和 P2P 频率。                   |
| **样板 P2P 单元（管理）** | 作为一个处理端点参与分发，并协调多个已绑定的功能端口；提供福鲁伊克斯原色和全部 AE2 线缆颜色。               |
| **样板 P2P 单元端口**     | 传输、掉落、放置、返回、提取、收集、破坏、红石和能量九种端口提供材料路由与世界交互，均不额外占用频道。      |
| **产物提取卡**            | 让 AE2 样板供应器主动从相邻机器提取经过过滤的产物；仅在 Minecraft `1.20.1` 和 `1.21.1` 提供。               |
| **ME 部件放置器**         | 使用玩家背包或 AE 网络中的材料，在最大 `16 x 16` 的点、线或平面范围内批量放置 AE 线缆和线缆部件。           |
| **样板配置**              | 为材料设置输入面以及普通、掉落或放置输出形式；Minecraft `1.21.1` 还提供批次分发和逐样板批次配置。           |

所有支持版本的收集端口都能收集掉落物。Minecraft `1.20.1` 和 `1.21.1` 还可以收集源流体；`1.16.5` 和 `1.12.2` 只收集物品。

## 为什么使用它？

- **并行加工：**处理任务在可用机器之间轮询分配，不会总是使用第一台机器。
- **节省频道：**只有样板 P2P 输入端占用 `1` 个频道；输出端、单元管理器和单元端口均不占频道。
- **集中管理样板：**处理样板保留在一个 AE2 样板供应器中，无需为每台机器复制一套样板。
- **灵活自动化：**单元端口可以路由材料、与世界交互、返回产物、输出红石和供应 FE。
- **自动返回产物：**输出端和返回类型端口可以通过输入端把任务产物送回样板供应器。
- **集中供能：**能量端可以为子网供能，并在符合条件的端点之间分配 FE。
- **快速扩建：**ME 部件放置器可以一次铺设整排或整面的线缆与部件端点。

## 快速上手

### 搭建并行机器组

1. 将处理样板放入主网中的 AE2 **样板供应器**；旧版本 AE2 使用 **ME 接口**。
2. 搭建一个已经供能的 AE 子网，并安装 **样板 P2P 通道（输入）**，让它的正面贴住该方块的输出面。
3. 在同一子网中为每台加工机器安装一个 **样板 P2P 通道（输出）**，并让输出端正面朝向机器。
4. 使用 AE2 记忆卡 `Shift + 右击` 输入端，生成并保存频率。
5. 使用同一张记忆卡右击所有输出端，写入相同频率。
6. 发起处理任务；输入端会选择下一个可用端点并向其发送任务。

输入端和所有端点必须位于同一个 AE 子网、获得供能并保持区块加载。频率 `0000` 表示尚未配置。离线、未加载、忙碌或被阻塞的端点会被跳过。

默认的 **完整下发**会把一份完整任务交给一个端点。例如，`100A + 800B -> 100C` 必须能够被一台机器完整接收后才会下发。

Minecraft `1.21.1` 还提供 **批次分发**。先在输入端的通用配置中选择该模式，再把鼠标悬停在处理样板的主产物上，按
`Ctrl + 鼠标中键` 打开批次配置。对于 `100A + 800B -> 100C`，批次数量 `100` 表示一份原子任务为 `1A + 8B -> 1C`
；输入端会按机器容量分配原子任务的整数倍，尚未发送的材料继续由样板供应器保管。系统只检查数量能否整除，玩家仍须确保配置比例与机器真实配方一致。

### 搭建样板 P2P 单元

当处理流程需要多种材料输入方式、返回路径或世界交互，而不是单一机器输入面时，可以使用样板 P2P 单元。

1. 将 **样板 P2P 单元（管理）**作为线缆中心安装在子网中。
2. 用记忆卡把样板 P2P 输入端的频率写入管理器。
3. 使用记忆卡 `Shift + 右击` 管理器，保存该管理器的身份。
4. 使用同一张记忆卡右击每个功能端口，将端口绑定到该管理器。
5. 在处理样板模式下，将鼠标悬停在输入材料上并按 `Ctrl + 鼠标中键`，设置材料输入面以及普通、掉落或放置输出形式。

管理器会与普通输出端一起参与端点分发。它的端口必须位于同一个 AE 子网，并保持绑定到该管理器的身份。

### 可选自动化

- 在样板 P2P 输入端配置返回模式和产物提取；同步主端配置的单元管理器会在任务期间把这些设置应用到绑定端口。
- 在 Minecraft `1.20.1` 和 `1.21.1` 中，可以把 **产物提取卡**安装到样板供应器，用于配置该供应器自己的相邻机器提取和产物过滤。
- 将**样板 P2P 通道（能量）**朝向 FE 来源安装，为子网和符合条件的机器供能；在 GUI 中选择被动/主动输入及均分/轮询方式。
- 使用 **ME 部件放置器**选择点、线或平面，设置线缆、部件和可选的记忆卡频率，即可一次放置全部端点。

## 游戏内指南

Minecraft `1.20.1` 和 `1.21.1` 在安装 [GuideME](https://modrinth.com/mod/guideme) 后提供中英文游戏内指南。将鼠标悬停在本模组物品上并按
AE2 指南键 `G`，即可打开对应页面。两个版本的指南都包含配方、搭建流程、单元端口、产物返回、能量设置和任务重置说明；`1.21.1`
指南还包含批次分发。
