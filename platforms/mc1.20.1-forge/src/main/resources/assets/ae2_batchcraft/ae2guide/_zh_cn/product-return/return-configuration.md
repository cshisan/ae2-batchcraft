# 产物返回配置

返回模式控制活动任务期间输出端或单元允许接收哪些资源类型，不改变 ME 存储容量，也不负责开启主动提取。

| 模式 | 接收资源 | 任务顺序 | 建议用途 |
| --- | --- | --- | --- |
| **严格模式** | 活动样板声明的产物与副产物类型 | 当前批次结束前不接受不同样板 | 共用或可能混入杂物的返回路径 |
| **无阻挡** | 任意返回资源 | 不因上一任务产物阻挡新样板 | 独立的机器输出路径 |

严格模式只比较资源类型，不能证明机器确实完成配方，也不会将返回数量限制为样板声明数量。如果其他流程可能提前产生同类型产物，应隔离该流程或返回路径。

输入端通用配置页是集中配置入口。普通输出端可跟随输入端，也可使用本地返回模式；单元管理器同样可同步输入端的返回、破坏回收、红石及脉冲设置，或保留本地值。

全部材料下发前返回产物是允许的。待下发队列未清空时任务不能结束，所以提前返回不会丢失仍待输出的材料。
