# Getting Started

Build the smallest working network first, then configure frequency binding and product return.

1. Place the input against a Pattern Provider output face.
2. Place one or more outputs against processing machines.
3. Create a frequency on the input and load it into every endpoint.
4. Encode a processing pattern and request a crafting job.
5. Confirm that all ingredients leave the endpoint and the declared product returns.

> A job is never split internally. Distribution happens between complete jobs, not between item quantities inside one job.
