# 产物返回流程

产物通过拥有当前任务的端点返回。普通输出端使用自己的返回入口；单元则经返回、收集、破坏或提取端口进入管理器的返回路径。

## 返回顺序

1. 端点先应用当前产物返回规则。
2. 如果样板供应器已有返回槽内容，端点先请求立即冲刷。
3. 可接收的资源进入样板供应器返回槽。
4. 在同一次调用内，经 AE2 原有合成返回路径尝试注入 ME 存储。
5. 无法进入网络的内容继续由 AE2 原有 tick 逻辑处理。

请求立即冲刷前会先检查返回槽，空返回槽不会产生无意义调用。

## ME 存储已满

产物会保留，不会被删除。AE2 继续按原有 tick 重试。后续重试成功回网后，来源端点会被唤醒，恢复即时高吞吐返回。

## 任务完成

声明的主产物可以提前满足任务的产物条件。待下发材料单独记录，因此端点不会丢弃尚未发送的材料。

筛选规则见[产物返回配置](../product-return/return-configuration.md)，主动拉取见[端点主动提取](../product-return/endpoint-extraction.md)。
