# 材料输出方向

在 AE2 样板编码终端的处理样板模式中，`Ctrl + 鼠标中键`有两种目标：

| 鼠标所在槽位 | 配置内容 |
| --- | --- |
| 输入材料 | 输出形式和方向 |
| 主产物 | 批次数量 |

两种配置都会写入编码后的样板并显示在悬浮提示中。批次数量只影响输入端的批次分发模式。

| 输出形式 | 单元目标 |
| --- | --- |
| 普通 | 传输端口 |
| 掉落 | 投掷端口 |
| 放置 | 放置端口 |

**自动方向**使用相应端点连接机器的面。顶面、北面等显式方向是绝对世界方向，不会在目标拒绝时回退到连接面。

编码样板悬浮提示没有配置时，确认终端处于处理样板模式，重新配置目标槽位后再点击**编写样板**。把样板放入 AE2 样板供应器前，应先检查最终编码样板。

标准样板供应器会忽略 BatchCraft 的输出形式扩展；它由样板 P2P 输出端和单元材料端口解释。

批次数量的校验与下发行为见[批次分发](../pattern-p2p/batch-distribution.md)。
