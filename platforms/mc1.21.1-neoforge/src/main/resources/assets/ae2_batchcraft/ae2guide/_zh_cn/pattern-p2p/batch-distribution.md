# 批次分发

输入端的通用配置提供两种分发模式。

| 模式 | 行为 |
| --- | --- |
| **完整下发** | 必须由一个端点一次接收整次处理推送 |
| **批次分发** | 可按已配置最小份数的整数倍分多次下发 |

## 配置样板

在 AE2 样板编码终端的处理样板模式中，将鼠标移到主产物上并按 `Ctrl + 鼠标中键`。输入**批次数量**后按**确定**或回车。未确认就关闭或返回不会保存编辑值。

默认值和最小值都是 `1`，最大值由编码的输入与产物数量限制。超过最大值会修正为最大值；不能整除所有声明数量时会修正为 `1`。

系统只能证明编码数量可以整除，不能证明相邻库存实际接受的最小配方。例如实际最小配方是 `2A + 2B -> 2C`，样板是 `4A + 4B -> 4C`，批次数量设为 `4` 会描述成 `1A + 1B -> 1C`，目标可能永远无法启动。批次数量必须保留实际最小配方比例。

## 材料下发

批次数量是最多可划分的份数，不是必须使用的端点数量。输入端根据当前可用端点及其当前容量进行规划。每个选中端点会一次接收若干整数份的聚合材料，不会为每一份分别创建任务。

尚未请求的材料留在相邻 AE2 样板供应器中。端点重新出现容量时，输入端会继续请求并分发下一份材料。已经进入输入端的材料会保持跟踪，直到分配到的端点接收。

只有匹配的处理样板可以延续同一活动任务系列。新放置的输入端没有旧任务上下文，会拒绝此前会话遗留的材料，直到收到有效的处理样板请求。

另见[样板P2P通道(输入)](input.md)和[材料输出方向](../troubleshooting/material-directions.md)。
