# 选择产物返回模式

机器产物路径完全独立且不会混入无关资源时使用**无阻挡**；多个产物共用返回路径、需要拒绝活动样板未声明类型时使用**严格模式**。

返回被拒绝时按以下顺序检查：

1. 确认端点正在处理预期样板。
2. 对照返回资源类型与样板声明的产物、副产物。
3. 检查输出端或管理器是否正在同步输入端配置。
4. 仅为区分规则不匹配与 ME 已满，可临时切换无阻挡。

严格模式不能验证机器是否真正完成配方，也不限制返回数量。预期类型可能提前被接受，但任务仍会继续下发全部待下发材料。
