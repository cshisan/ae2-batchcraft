# 样板P2P通道(输入)

<RecipeFor id="ae2_batchcraft:pattern_p2p_tunnel_input" />

从正面的样板供应器接收完整处理任务，并在同频率的普通输出端和单元管理器之间分配。

| 属性 | 值 |
| --- | --- |
| AE 频道 | `1` |
| 频率 | 必须配置；`0000` 表示停用 |
| 相邻方块 | 样板供应器输出面 |
| 任务拆分 | 只在完整任务之间分配 |
| 任务分配方式 | 轮询、随机或优先 |

## 任务分配

右侧功能栏的任务分配按钮控制端点选择方式。**轮询**从保存的游标开始，成功选择后推进游标；**随机**先随机选择起点，失败后继续尝试其他端点；**优先**每次都从第一个端点开始，前面的端点失败后才继续尝试后面的端点。

离线、未加载、忙碌、不在同一网络或无法接收完整材料计划的端点不可用。选中的端点接收该次处理推送的全部数量。

## 通用配置

输入端提供以下默认值：

- 产物返回模式。
- 轮询、随机或优先任务分配。
- 是否允许普通输出端主动提取产物。
- 普通输出端和单元提取端口的提取间隔与数量。
- 单元破坏回收和红石行为。
- 单端口单槽、传输以及单元能源端口的分配设置。

任务执行期间修改这些配置也会动态广播。开启同步的输出端和单元管理器会应用后续修改，无需重新下单；关闭同步的端点继续使用本地值。

普通输出端和单元管理器始终保留本地值。开启同步时，输入端广播会覆盖当前本地值；关闭同步时忽略广播并继续使用本地值。再次开启同步会立即应用当前输入端配置。

## 重置任务状态

从输入端重置，会影响当前频率和当前 AE 网络中所有已加载的普通输出端和单元管理器。

> 重置会永久销毁这些端点中仍待下发的材料。未加载端点无法远程重置。
