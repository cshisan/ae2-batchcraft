# 任务状态与重置

重置用于恢复已无法正常完成的任务，不是常规取消合成手段。

| 重置位置 | 影响范围 |
| --- | --- |
| 普通输出端 | 该输出端的活动任务 |
| 单元管理器 | 该单元的活动任务 |
| 样板 P2P 输入端 | 当前频率与当前 AE 子网中所有已加载输出端和管理器 |

重置会永久销毁受影响端点待下发队列中的材料，因此每次都需要确认。执行前确认机器已经收到全部所需材料。未加载端点无法远程重置，重新加载前会保留自己的状态。

重置前先检查返回路径、ME 容量、机器输出面，以及是否仍有一种材料因目标阻塞而等待。产物已经返回但待下发材料未清空时，任务继续活动属于正常行为。
