# ME Component Placer

<ItemImage id="ae2_batchcraft:component_placer" scale="3" />

Places cables and parts in bulk, and saves or loads settings like an AE2 memory card.<br />&#160;<br />

## Placement Mode

**Select an area:** Shift-right-click the start and right-click the end. Points, lines and planes are supported, up to 16 blocks per axis.<br />&#160;<br />

**Choose what to place:** Right-click air to open the screen. Mark a cable and part, set direction and offsets, then place them. Parts can also be added to matching cables already present.<br />&#160;<br />

**Supply materials:** Use materials in the tool, or link it in an AE2 wireless access point's linking slot to use network stock. A crafting card allows crafting requests for missing materials.<br />&#160;<br />

## Frequency and Unit ID

**Switch modes:** Shift-scroll while holding the tool to switch between placement and frequency modes.<br />&#160;<br />

**Save and load:** In frequency mode, hold the tool in your main hand. Shift-right-click a memory-card-compatible target to save, or right-click to load. Available settings depend on the target, including vanilla P2P settings, frequency and unit ID.<br />&#160;<br />

**Screen controls:** Pick up a memory card with the cursor and right-click the frequency or unit ID color square to load that setting. Left-click clears it. An invalid card value leaves the setting unchanged; the card is not consumed.<br />&#160;<br />

**Clear settings:** In frequency mode, shift-right-click a block without memory card interaction to clear saved settings. Right-clicking air still opens the tool screen.<br />&#160;<br />

## Notes

**Area and offsets:** Three-dimensional regions are not supported. Selection does not move up a block automatically; use offsets to adjust placement.<br />&#160;<br />

**Energy and materials:** Survival mode requires tool energy. Creative mode needs no tool energy but still consumes the required cables and parts.<br />&#160;<br />

**Wireless range:** Network materials require a valid link and wireless access point coverage, including in Creative mode.<br />&#160;<br />

**Upgrades:** Supports one crafting card and two energy cards.
