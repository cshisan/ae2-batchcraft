# ME部件放置器

<ItemImage id="ae2_batchcraft:component_placer" scale="3" />

批量放置线缆与部件的工具，也能像 AE2 内存卡一样保存、加载配置。<br />&#160;<br />

## 放置模式

**选择范围：** 潜行右键记录起点，右键记录终点。支持点、线和平面，每轴最多 16 格。<br />&#160;<br />

**设置内容：** 右键空气打开界面，标记线缆与部件，选择朝向和偏移后执行放置。已有相同线缆的位置也能继续放置部件。<br />&#160;<br />

**材料来源：** 可使用工具中的材料。将工具放入 AE2 无线访问点的绑定槽后，也可使用网络材料；合成卡可在缺料时发起合成请求。<br />&#160;<br />

## 频率与单元 ID

**切换模式：** 手持工具时潜行滚轮，切换放置与频率模式。<br />&#160;<br />

**保存和加载：** 频率模式下主手持工具，潜行右键支持内存卡的目标保存配置，右键目标加载。可处理原版 P2P、频率及单元 ID 等目标支持的配置。<br />&#160;<br />

**界面操作：** 鼠标拿起内存卡后，右键频率或单元 ID 色块加载该项；左键清除该项。卡内没有有效值时保留原设置，内存卡不会被消耗。<br />&#160;<br />

**清除配置：** 频率模式下潜行右键不支持内存卡交互的方块，会清除已保存配置。右键空气仍打开工具界面。<br />&#160;<br />

## 特殊使用说明

**范围与偏移：** 不支持立体区域，选点不会自动上移一格；需要移动放置位置时使用偏移设置。<br />&#160;<br />

**电量与材料：** 生存模式需为工具充电。创造模式免工具电量，但仍消耗所需线缆与部件。<br />&#160;<br />

**无线范围：** 使用网络材料需要有效绑定，并处于无线访问点的覆盖范围内，创造模式也适用。<br />&#160;<br />

**升级卡：** 支持一张合成卡和两张能源卡。
