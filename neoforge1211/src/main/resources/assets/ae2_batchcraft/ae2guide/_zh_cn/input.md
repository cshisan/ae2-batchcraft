# 样板P2MP输入端

<ItemImage id="ae2_batchcraft:pp2mp_input" scale="3" />

接收相邻样板供应器的处理任务，并把任务分配给同频率输出端或单元管理器的部件。<br />&#160;<br />

## 使用

**连接供应器：** 让供应器朝向输入端正面，并按[快速开始](getting_started.md)为执行端绑定频率。<br />&#160;<br />

**任务分配：** 轮询、随机和优先级决定优先把任务交给哪个可用的输出端或管理器。<br />&#160;<br />

**投料方式：** 完整下发把整份材料交给一个执行端；[批次分发](batch.md)按样板设置分成较小批次。<br />&#160;<br />

**统一配置：** 开启同步的输出端和管理器可跟随输入端设置，减少重复配置。<br />&#160;<br />

## 特殊使用说明

**运行条件：** 输入端需要电力与频道，执行端必须位于同一 AE 网络并使用相同频率。<br />&#160;<br />

**接收新任务：** 目标无法接收材料时会等待；是否等待上一笔产物返回，由[阻挡模式](configuration.md)决定。<br />&#160;<br />

**重置范围：** 重置输入端会影响同频率执行端的任务。操作前请查看[任务重置说明](configuration.md)。
