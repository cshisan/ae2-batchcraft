# AE2 批量工艺

把一个样板供应器的处理任务分配给多台机器。可使用输出端连接普通机器，也可用单元管理器组合投料、产物回收和红石控制等功能。<br />&#160;<br />

**初次使用：** 从[快速开始](getting_started.md)选择连接方式，再按对应物品页面完成设置。<br />&#160;<br />

**配置说明：** [公共配置](configuration.md)介绍阻挡、产物返回、提取和任务重置；[单元管理器](unit/manager.md)介绍四种投料模式。<br />&#160;<br />

**辅助工具：** [假合成转换器](fake_crafting_converter.md)用票据表示合成任务；[ME部件放置器](component_placer.md)批量布置线缆与部件；[ME IO 端口](io_port.md)填充、清空和转移存储元件。<br />&#160;<br />

**查找物品说明：** 鼠标悬浮本模组物品，按住指南快捷键（默认 `G`）可打开对应页面。<br />&#160;<br />
