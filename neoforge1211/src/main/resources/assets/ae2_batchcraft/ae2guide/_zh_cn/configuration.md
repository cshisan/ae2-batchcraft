# 公共配置

输出端和单元管理器的公共设置，用于控制产物返回、连续接单、配置同步和任务重置。<br />&#160;<br />

## 返回模式

**严格：完整匹配。** 资源及附加数据都必须一致，包括物品的名称、附魔等。<br />&#160;<br />

**严格：忽略NBT。** 物品只忽略自定义 NBT，名称、附魔等其他属性仍需一致。<br />&#160;<br />

**严格：仅物品ID。** 按同类资源的注册 ID 匹配，不比较附加属性。<br />&#160;<br />

**无阻挡。** 任务期间可接收样板未声明的资源，但只有与所需产物完整匹配的资源才计入完成数量。<br />&#160;<br />

**任务完成：** 普通任务等待全部声明产物达量；假合成按[真实产物标记](fake_crafting_converter.md)判断。任务期间允许返回超出要求的数量。上述设置不会改变 AE2 自身的合成匹配规则。<br />&#160;<br />

## 阻挡模式

**开启（默认）：** 等当前任务完成后再接收下一笔，完整下发和批次分发都适用。<br />&#160;<br />

**关闭：** 上一笔材料全部送出且目标能接收新材料后，可继续接单，无需等待上一笔产物。尚有材料需要送出或退回时仍需等待。<br />&#160;<br />

**重新开启：** 已有任务继续运行，全部结束后才能再接单。同种产物依次用于完成先接收的任务。<br />&#160;<br />

**配置区别：** 返回模式中的“无阻挡”决定允许接收什么；这里的阻挡模式决定何时接收新任务。<br />&#160;<br />

**红石配方：** 并发任务的脉冲可能重叠。机器需要每笔任务单独触发时，请保持阻挡开启。<br />&#160;<br />

## 同步与提取

**跟随设置：** 输出端和管理器可跟随输入端的任务设置；供应过滤的同步关系见[供应过滤](provider_filter.md)。同步中的设置只读，关闭后保留当前值。<br />&#160;<br />

**提取位置：** 产物提取开关控制普通输出端。管理器的提取参数用于提取、收集端口；资源接收端的主动获取单独设置。<br />&#160;<br />

**间隔与数量：** 提取间隔最小为 `1 tick`，数量为每轮上限，实际受来源、机器接口及返回容量限制。收集掉落物的数量含义见[收集端口](unit/collect.md)。<br />&#160;<br />

**重新开始：** 空闲或目标堵塞后恢复提取，可能有短暂等待。<br />&#160;<br />

## 重置任务

**重置范围：** 输入端重置会取消自身等待派发的批次，并重置同频率执行端；输出端和管理器只重置自身的全部任务。<br />&#160;<br />

**材料与合成：** 尚未送出的材料会等待退回；已送入机器的材料、已放置或破坏的方块不会恢复。AE2 CPU 中的合成任务需另外取消。
