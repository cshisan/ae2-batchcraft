# 供应过滤

决定持续供应允许发送哪些资源，以及目标库存需要维持多少。<br />&#160;<br />

## 使用

**白名单：** 标记允许供应的资源；中键点击标记可设置目标数量，`0` 表示不限量。<br />&#160;<br />

**黑名单：** 放入反相卡后，改为排除所标记的资源，目标数量不再生效。<br />&#160;<br />

**配置位置：** 在资源接收端、输出端或管理器的供应过滤页面设置；[供应端口](unit/provider.md)也可直接设置。<br />&#160;<br />

**同步配置：** 输出端和管理器可跟随资源接收端，供应端口可跟随管理器。需要独立设置时关闭同步。<br />&#160;<br />

## 特殊使用说明

**空过滤：** 没有标记资源时允许全部资源。<br />&#160;<br />

**目标数量：** 表示目标库存希望维持的数量，不是每次发送数量。机器库存无法可靠读取时，无法保证精确维持该数量。<br />&#160;<br />

**虚拟反相卡：** 同步显示的反相卡仅表示正在使用黑名单，不能取出。
