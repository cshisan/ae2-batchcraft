# 快速开始

通过输入端把样板供应器的处理任务交给输出端或单元管理器，适合让多台机器共同承担加工任务。<br />&#160;<br />

## 选择连接方式

**普通机器：** 样板供应器 → [输入端](input.md) → [输出端](output.md) → 机器。适合从同一连接位置投料和返回产物。<br />&#160;<br />

**多位置或世界加工：** 样板供应器 → [输入端](input.md) → [单元管理器](unit/manager.md) → 单元端口。适合分开连接机器的输入、输出位置，或使用掉落、放置、收集、破坏和红石功能。<br />&#160;<br />

## 使用

**连接网络：** 样板供应器朝向输入端正面；输入端与输出端、管理器接入同一个通电的 AE 网络。输入端需要频道。<br />&#160;<br />

**绑定频率：** 手持内存卡，潜行右键输入端保存频率，再右键输出端或管理器加载。单元端口还需从所属管理器加载频率与单元 ID，见[绑定说明](unit/manager.md)。<br />&#160;<br />

**配置样板：** 在供应器中放入处理样板。需要材料输出方式、空槽配置或批次设置时，使用 [PP2MP 样板](pattern.md)。<br />&#160;<br />

**安排产物返回：** 让机器主动把产物送回，或使用输出端的产物提取、单元提取端口。产物会返回输入端所连接的原样板供应器。<br />&#160;<br />

## 特殊使用说明

**机器接口：** 机器连接面必须允许投料和所选的返回方式。仅接通网络不能替代机器自身的输入、输出设置。<br />&#160;<br />

**等待任务：** 需要在等待产物时继续投料，可关闭[阻挡模式](configuration.md)；上一笔材料未送完时仍需等待。
