# 批次分发

把一份处理配方分成固定数量的小批次，减少每次送入机器的材料，适合无法一次容纳整份大配方的机器。<br />&#160;<br />

## 使用

**设置批数：** 在 PP2MP 编码界面对第一个产物按 `Ctrl+鼠标中键`，设置批次数量并编写样板；输入端选择批次分发。<br />&#160;<br />

**示例：** `4A + 4B → 4C` 设置为 `2` 批，每批投送 `2A + 2B`，要求返回 `2C`。<br />&#160;<br />

**连续加工：** 是否等待上一批产物，由[阻挡模式](configuration.md)决定。没有可用执行端时，已接收的材料会等待派发。<br />&#160;<br />

## 特殊使用说明

**数量整除：** 批数必须整除材料、产物及假合成真实产物标记的数量。<br />&#160;<br />

**机器配方：** 每批材料必须满足机器的实际配方。机器若需要 `2A + 2B`，上例就不能拆成 `4` 批；机器容量不足时也不会自动缩小每批数量。
