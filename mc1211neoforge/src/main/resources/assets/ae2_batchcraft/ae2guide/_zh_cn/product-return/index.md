# 产物返回与提取

产物可通过普通输出端、具备返回能力的单元端口，或装有产物提取卡的样板供应器进入 AE 网络。这些路径共用存储容量，但配置来源和任务条件相互独立。

| 返回路径 | 来源 | 需要活动 P2P 任务 | 配置来源 |
| --- | --- | --- | --- |
| 普通输出端被动返回 | 机器推入输出端 | 是 | 输出端或同步的输入端 |
| 普通输出端主动提取 | 输出端从机器拉取 | 是 | 输入端 |
| 单元返回/收集/破坏/提取 | 单元端口 | 是 | 单元管理器或同步的输入端 |
| 产物提取卡 | 样板供应器从机器拉取 | 不需要 P2P 任务 | 提取卡界面 |

返回资源先经过所属样板供应器的返回槽。有空间时，BatchCraft 会要求供应器冲刷已有返回槽、写入新资源，并在同一次调用内立即尝试注入 ME。这样保留了 AE2 原有返回槽和合成完成回调，同时避免九个返回槽成为吞吐瓶颈。

ME 存储已满时，资源留在返回槽，由 AE2 原有 tick 重试。后续重试一旦成功，来源端点会被唤醒并恢复即时返回。
