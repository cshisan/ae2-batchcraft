# 样板P2P通道(能量)

<RecipeFor id="ae2_batchcraft:pattern_p2p_tunnel_energy" />

从正面的方块接收 FE，优先为所在 AE 子网供能，再把剩余 FE 分配给符合条件的普通输出端和单元能源端口。

| 属性 | 值 |
| --- | --- |
| AE 频道 | `0` |
| 频率 | 能量通道不使用频率 |
| 输入资源 | FE |
| 输出范围 | 当前 AE 网络 |
| 合成任务 | 供能不需要活动任务 |

## 输入模式

| 模式 | 行为 |
| --- | --- |
| 被动接收 | 只接收相邻能源主动推入的 FE |
| 主动拉取 | 接收推入，同时主动向相邻能源请求 FE |

## 可供能目标

普通输出端需要非零频率和活动 AE 节点。单元能源端口需要绑定同网的有效管理器。**两类目标接收 FE 都不需要活动合成任务。**

## 分配模式

| 模式 | 行为 |
| --- | --- |
| 均分 | 尽量按当前需求平均分配 FE |
| 轮询 | 轮换接收者优先级，适合供能无法满足全部需求时 |

能量端的分配模式用于第一级分配：接收者先按输出端频率或单元身份归组，再由能量端在这些组之间分配 FE。普通输出端组内继续使用该模式；每个单元组收到 FE 后，再使用输入端或对应单元管理器的“单元端口（能量）”配置，在所属能源端口之间进行第二级分配。

样板P2P通道(能量)不会向正对着它的另一个能量通道输送 FE。单元的持续供能行为见[单元能源端口](../unit/energy-port.md)。
