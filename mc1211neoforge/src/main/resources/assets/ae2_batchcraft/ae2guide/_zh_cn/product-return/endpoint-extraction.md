# 端点主动提取

端点主动提取会从端点正面的库存或资源能力拉取产物，不再依赖机器主动推送。

| 输入端设置 | 普通输出端 | 单元提取端口 |
| --- | --- | --- |
| 产物提取开关 | 开启或关闭提取能力 | 忽略 |
| 提取间隔 | 生效 | 经管理器生效 |
| 提取数量 | 生效 | 经管理器生效 |

因此开关只控制普通输出端是否拥有提取能力；间隔和数量同时影响两类端点。普通输出端和单元提取端口开始新的提取都要求任务处于活动且可运行状态，无阻挡模式不会绕过此要求。

配置的提取数量是一次调度可处理的最大资源操作预算，不承诺在一个 tick 内全部移动。库存可提供的数量较少时实际提取会更少；数量很大时可能需要后续 tick 继续。

每个提取端点每 tick 最多完成 `64` 个成功返回库存轮次，同一 AE 网络上的全部提取端点每 tick 共享 `256` 个成功轮次。一个轮次可以移动同一种资源的多个单位；这些限制统计成功轮次，不按单个物品或流体单位计数。

一个轮次成功进入 AE 网络后，返回库存可在同一 tick 继续复用。ME 存储或返回库存无法再接收资源时，端点会停止提取，不会继续从相邻库存拉取。已经进入返回库存的资源会保留并继续重试；因共享预算延后的端点会在后续 tick 继续。

连续空提取会逐步增加退避，最多额外 `20` tick。库存变化或返回容量恢复可提前唤醒等待中的提取器；成功提取后仍会遵守配置的最小间隔。

材料尚未全部下发时也可开始提取。任务会保持活动直到待下发队列清空。已拉出但无法立即返回的资源进入恢复队列继续重试，不会静默删除。

恢复队列可以在任务结束后继续排空。它只包含已经拉出、等待返回的资源，不会在任务结束后启动新的提取。

相邻库存已经能可靠直接返回产物时优先使用直接返回；必须主动拉取产物或需要配置拉取速率时再启用主动提取。
