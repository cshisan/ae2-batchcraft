# 样板P2P通道(输入)

<RecipeFor id="ae2_batchcraft:pattern_p2p_tunnel_input" />

从正面的 AE2 样板供应器接收处理任务，并在同频率的普通输出端和单元管理器之间分配。

| 属性 | 值 |
| --- | --- |
| AE 频道 | `1` |
| 频率 | 必须配置；`0000` 表示停用 |
| 相邻方块 | 样板供应器输出面 |
| 分发模式 | 完整下发或批次分发 |
| 任务分配方式 | 轮询、随机或优先 |

## 任务分配

在**完整下发**中，选中的一个端点接收整次处理推送。离线、未加载、忙碌或无法兼容任务的端点不可用。

在**批次分发**中，输入端只向相邻 AE2 样板供应器请求下一份已规划材料，并按已配置最小份数的整数倍分配。尚未下发的材料继续留在样板供应器中，直到端点重新具备容量。启用前请先阅读[批次分发](batch-distribution.md)。

右侧功能栏的任务分配按钮控制端点选择方式。**轮询**从保存的游标开始，成功选择后推进游标；**随机**先随机选择起点，失败后继续尝试其他端点；**优先**每次都从第一个端点开始，前面的端点失败后才继续尝试后面的端点。

## 通用配置

GUI 右侧最上方的分页分组按钮在“输出端分页分组”和“单元分页分组”之间循环切换左侧分页集合。“通用配置”是两个分组共享的同一个页面；切换分组不会复制或重置其中的数据。单元分组中的四个端口分页共用一个左侧按钮，按传输、破坏、红石、能量的顺序循环切换。

输入端提供以下默认值：

- 产物返回模式。
- 完整下发或批次分发。
- 轮询、随机或优先任务分配。
- 是否允许普通输出端主动提取产物。
- 普通输出端和单元提取端口的提取间隔与数量。
- 单元破坏回收和红石行为。
- 单端口单槽、传输模式和单元能源端口的第二级分配模式。

普通输出端的产物提取“开启/关闭”按钮位于“输出端通用配置”；提取间隔和数量仍位于共享的“通用配置”。其余单元级设置按“单元通用配置”和各单元端口分页分类。

任务执行期间修改这些配置也会动态广播。开启同步的输出端和单元管理器会应用后续修改，无需重新下单；关闭同步的端点继续使用本地值。

普通输出端和单元管理器始终保留本地值。开启同步时，输入端广播会覆盖当前本地值；关闭同步时忽略广播。再次开启同步会立即应用当前输入端配置。

## 重置任务状态

从输入端重置，会影响当前频率和当前 AE 网络中所有已加载的普通输出端和单元管理器。

> 重置会永久销毁这些端点中仍待下发的材料。未加载端点无法远程重置。
