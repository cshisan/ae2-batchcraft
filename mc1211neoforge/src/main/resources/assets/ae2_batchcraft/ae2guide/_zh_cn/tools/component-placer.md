# ME 部件放置器

<RecipeFor id="ae2_batchcraft:component_placer" />

带电放置器可在选中的点、线或平面上重复放置一种线缆和一种线缆部件。

## 选择与配置

1. 对方块`潜行 + 右击`记录第一点，再右击第二点。可选择点、线或平面，不允许立体范围。
2. 打开界面并标记线缆和/或线缆部件。标记槽只记录物品类型，不消耗样品。
3. 选择部件朝向；X、Y、Z 偏移会相对已保存范围移动放置位置。
4. 可将 AE2 记忆卡放在光标、主手或副手，右击频率控件加载 P2P 频率；左击重置为 `0000`。
5. 点击**放置**。已有方块或部件的目标会被跳过，不会被替换。

| 限制或来源 | 行为 |
| --- | --- |
| 选择范围 | 每轴最多 `16` 格；平面最多 `16x16` |
| 材料 | 优先连接的 AE 网络，其次九个本地材料槽 |
| 网络材料不足 | 装有合成卡且条件允许时打开 AE2 合成数量界面 |
| 能量 | 消耗工具内部 AE 电量，支持能源卡 |

放置**样板 P2P 输入端**时会故意忽略已加载频率，避免创建同频率的重复输入端；其他支持的 P2P 部件可获得显示频率。朝向、偏移、标记、选择范围和显示频率都会保存在工具中，直到修改或清除。
